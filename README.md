# ZapRunner — E-Commerce de Zapatillas

Proyecto académico de tienda virtual desarrollado con Next.js y Tailwind CSS, estructurado para prácticas de CI/CD con GitHub Actions y Azure DevOps.

## Arquitectura de Carpetas

- `app/`: Contiene las páginas y rutas principales de la aplicación (`page.tsx`).
- `components/`: Componentes reutilizables de la interfaz (Navbar, modales, tarjetas de productos).
- `.github/workflows/`: Automatizaciones de canalización CI/CD con GitHub Actions.

## Tecnologías Utilizadas

- **Framework:** Next.js
- **Estilos:** Tailwind CSS
- **Control de Versiones:** Git & GitHub
